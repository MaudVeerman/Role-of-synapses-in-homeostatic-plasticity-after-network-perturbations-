# UTwente — MSc report data, code & figures

Self-contained package to reproduce the results in the report.

## Structure

```
UTwente/
├── Codes/                       analysis code
│   ├── FM_results_final.ipynb   hypoxia / FM–synapsin silencing analysis + figures 5–9
│   ├── EM_results_final.ipynb   epilepsy / EM ultrastructure analysis + figures 11–14
│   ├── get_data_FM_final.py      builds per-field overlap CSVs from raw FM images
│   └── preprocessing_FM_final.py image pre-processing / channel assignment
├── data/
│   ├── FM_syn/                  per-coverslip overlap CSVs (puncta_analysis/overlap_summary.csv)
│   └── EM/                      AZ_all.csv, PD_all.csv, PC_all.csv, CL_all.csv, PD_assigned/ (ROI .zip)
└── figures/                    final result figures (Figure4–Figure14)
```

## Data availability

The raw microscopy images (the FM tif stacks and the EM tif images) are large and
are **not** included in this repository. They are stored on the group Synology
server and are available on request.

What the repository does contain is everything needed to reproduce the results
from the processed data:

- the per-coverslip FM overlap CSVs (`data/FM_syn/**/puncta_analysis/overlap_summary.csv`),
- the EM measurement CSVs (`data/EM/*_all.csv`), and
- the EM ROI annotations (`data/EM/PD_assigned/*.zip`) the EM CSVs were derived from.

## Running

Paths are repo-relative — no editing needed. Open a notebook in `Codes/` and run all cells.
Data locations can also be overridden with environment variables:

- `FM_DATA_DIR`  → defaults to `data/FM_syn`
- `EM_DATA_DIR`  → defaults to `data/EM`

Dependencies are listed in `environment.yml` and `Codes/requirements.txt`
(numpy, pandas, scipy, scikit-posthocs, scikit-image, matplotlib, seaborn, pillow, tifffile, read-roi).

The two `.py` scripts (`preprocessing_FM_final.py`, `get_data_FM_final.py`) rebuild the
CSVs from the raw images and are only needed if you have the raw data. When run, they
show a short instructions window and then a folder picker. Set `BATCH_MODE` at the top of
each script to process one folder (`False`) or several at once (`True`).

## Figures

- Figures 1–3 are illustrative or schematic and are not code-generated.
- Figures 5–9 are produced by `FM_results_final.ipynb`.
- Figures 11–14 are produced by `EM_results_final.ipynb`.
- Figures 4 (representative FM fields) and 10 (representative EM micrographs) are made from the raw images, which are archived separately (see Data availability), so they are included here as static images rather than regenerated by the notebooks.

## Notes

- FM pixel size: 0.057 µm/px (Nikon Plan Fluor 60×, DS-Fi1, 1280×960 field ≈ 3992 µm²).
